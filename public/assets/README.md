## Other assets

`svce-entrance.jpg` is a campus image used by the authentication UI as a fallback asset. Its source and licence attribution are documented in the interface component that displays it.

## Asset hygiene

- Use descriptive, stable filenames.
- Optimise large images before adding new ones.
- Do not add real complaint records, personal information, credentials, or other sensitive data to screenshots.
